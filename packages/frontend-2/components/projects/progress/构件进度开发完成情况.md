# 进度管理构件化开发完成情况

## 1. 文档目标

本文档用于记录当前已经落地的 `进度管理构件化数据设计` 实现内容，便于后续继续开发时快速判断：

- 哪些基础能力已经完成
- 哪些链路已经接入
- 当前还缺哪些页面切换和补充能力

对应设计文档：

- `构件进度数据设计.md`

## 2. 已完成范围

本轮已完成以下后端基础能力：

- 新增构件明细、事件、构件快照、任务快照相关数据表
- 新增对应 repository
- 新增派生数据同步服务
- 将计划任务更新、计划导入、实际记录新增/编辑/删除、实际 Excel 导入接入快照重算链路
- 新增构件快照、任务快照、统计接口
- 补充前端 API 协议层类型与请求方法

本轮未完成页面消费层切换：

- `physicalPage.vue` 尚未切换到 `element-snapshots`
- 任务列表或统计区尚未切换到 `task-snapshots` / `statistics`

## 8. 已新增查询接口

文件：

- `packages/server/modules/progress/rest/router.ts`

### 8.1 构件快照接口

- `GET /api/v1/projects/:projectId/progress/element-snapshots`

当前支持：

- `modelId`
- `progressStatus`
- `page`
- `limit`

### 8.2 任务快照接口

- `GET /api/v1/projects/:projectId/progress/task-snapshots`

当前支持：

- `taskStatus`
- `keyword`
- `page`
- `limit`

### 8.3 统计接口

- `GET /api/v1/projects/:projectId/progress/statistics`

当前已返回：

- 构件总数、完成数、进行中数、未开始数
- 提前完成、按期完成、延期完成
- 提前开始、延期完成构件数
- 任务总数、完成任务数、逾期任务数、进行中任务数、未开始任务数
- 总完成率
