# 进度管理当前实现说明

本文档用于沉淀当前 `进度管理` 模块已完成的前端实现，避免后续反复读取多个页面文件。当前实现对应以下页面：

- `schedulePage.vue`
- `actualPage.vue`
- `physicalPage.vue`

## 1. 当前实现定位

当前已完成的是一版**前端交互原型实现 + 部分真实接口接入**，目标是先把页面结构、字段、弹窗、导入导出入口、BIM 关联入口和页面联动口径固定下来，并逐步替换掉关键 mock 逻辑。

当前状态说明：

- 页面结构和交互已按最新需求补齐
- `BIM` 关联统一复用现有组件 `ObjectMultiSelectDrawer.vue`
- 用户选择统一复用现有组件 `DynamicApprovalUserField.vue`
- 构件关联口径统一为 `applicationId`
- 进度计划 `.mpp` 上传 / 下载、任务查询、任务 BIM 关联、`.mpp` 解析写入已接入真实 `REST` 接口
- 其他导入导出入口已具备前端交互
- 实际进度真实接口、Viewer 联动尚未接入
- 计划任务树已切换为后端真实数据驱动

已实现内容：

- 隐藏文件选择器，限制为 `.mpp`
- 当前项目、当前计划文件、最近更新时间、已关联任务数信息卡片
- 树形任务表格
- 任务展开 / 收起
- 计划字段展示：
  - 任务名称
  - 工期
  - 开始时间
  - 完成时间
  - 前置任务
  - 检验批
  - 关联状态
- 列表分页
- 单任务 `BIM` 关联弹窗
- 弹窗内接入 `CommonModelObjectMultiModelSelectDrawer`
- 保存后按 `selections(modelId + applicationIds)` 回写到本地任务数据
- 页面初始化时读取当前项目最新 `.mpp` 文件信息
- 页面初始化时读取当前项目任务树数据
- 上传 `.mpp` 时先走 blob 上传，再通过 `REST` 写入项目进度计划文件记录
- 上传 `.mpp` 后同步触发后端解析并写入计划任务表
- 下载时通过专用 `REST` 下载接口返回当前项目最新上传的原始 `.mpp` 文件
- 任务 `BIM` 关联保存已接入真实接口
- 无任务时会根据是否已上传计划文件展示“待解析”或“请先导入”空状态
- 成功操作提示

当前交互口径：

- 导入 `.mpp` 已接真实接口，上传成功后会刷新当前计划文件名与更新时间，并重新拉取任务树
- 上传接口会返回解析结果摘要：
  - 成功时返回导入任务数
  - 失败时保留原始文件记录，并返回解析失败原因
- 下载计划文件已接真实接口，默认下载当前项目最新上传的一份原始 `.mpp`
- 任务树通过真实 `REST` 接口读取
- BIM 关联保存后，调用真实接口持久化多模型分组 `selections(modelId + applicationIds)`
- 当前后端会在计划文件登记后，读取 blob 原始 `.mpp` 文件、调用本地 Java + MPXJ 解析器提取任务树，并直接写入计划任务表

当前后端接口：

- `GET /api/v1/projects/:projectId/progress/plan-file`
  - 获取当前项目最新一份计划文件记录
- `POST /api/v1/projects/:projectId/progress/plan-file`
  - 登记一条新的计划文件记录，并同步触发 `.mpp` 解析写入
- `GET /api/v1/projects/:projectId/progress/plan-file/download`
  - 下载当前项目最新一份计划文件原始文件
- `GET /api/v1/projects/:projectId/progress/plan-tasks`
  - 获取当前项目计划任务树原始列表
- `PUT /api/v1/projects/:projectId/progress/plan-tasks/:taskId/bim-association`
  - 保存单个任务的 BIM 关联，兼容旧 `modelId + applicationIds`，当前主口径为 `selections`
- `POST /api/v1/projects/:projectId/progress/plan-tasks/import`
  - 供后端 `.mpp` 解析结果写入计划任务台账

- “查看”详情使用独立弹窗与分段信息卡版式，不受新增 / 编辑表单布局影响

- 进度计划 `.mpp` 已切换为真实 `REST` 上传 / 下载
- 实际进度列表与新增 / 编辑 / 删除已切换为真实 `REST`
